# FC 26 Squads — экспериментальный патчер

**Это не готовый мод и не реализация всей спецификации. Не проверен в игре на PS4.** Перед экспериментами сохраните отдельную резервную копию сохранения. Пользуйтесь только файлами, на которые у вас есть права. В репозитории уже лежит архив PlayStation Pulse с DATA; условия его повторного распространения не установлены.

## Что работает

Скрипт использует [eafc-db-kit 1.1.0](https://github.com/ViniMacacari/eafc-db-kit) (MIT), читает FC 26 DB/сохранение, изменяет 34 атрибута игрока 20801, overall/potential, contractvaliduntil, preferredfoot, skillmoves, weakfootabilitytypecode, height, weight, facialhairtypecode, birthdate (5 февраля 2002), internationalrep, preferredposition1–3, socklengthcode и isretiring. Перезаписывает только перечисленные поля; остальные не трогает. Результат перечитывается и сверяется. Встроенная база — `DATA` из архива в репозитории, а не новая выгрузка трансферов. Скрипт не получает актуальные трансферы из интернета.

Опция `--transfer` освобождает номер 7 в Manchester United, меняя номер прежнего владельца на 14 (или первый свободный номер), затем вызывает механизм переноса библиотеки с сохранением сборной. В исходном DATA игрок 233064 получает номер 14, Роналду переходит из команды 112139 в МЮ под номером 7. Неоднозначные случаи прерываются. Затем скрипт меняет стандартную расстановку: Роналду выходит в стартовом составе МЮ и Португалии и назначается капитаном и исполнителем стандартов в командах и стандартных составах. При неподдерживаемой или неоднозначной расстановке выполнение прерывается. Изменения ещё не проверены в игре.

## Локальный запуск

Требуется Node.js 24+, npm. Извлеките **расшифрованный** файл `DATA` (или совместимый Squads/DB) и выполните:

```sh
npm ci
npm test
node src/patch.mjs /path/to/DATA /path/to/DATA.patched
# При желании попробовать трансфер:
node src/patch.mjs /path/to/DATA /path/to/DATA.patched --transfer
```

Выход не должен существовать; оригинал не перезаписывается. При ошибке не используйте выход, даже если файл успел появиться. Не запускайте патчер на зашифрованном сохранении. Кодирование бинарной DB и внутренние CRC выполняет библиотека; корректность внешней контрольной суммы, всех оболочек PS4 и работы на консоли **не подтверждена**.

## GitHub Actions

Workflow `Experimental squad patch` запускается также вручную через Actions → Run workflow. При ручном запуске перенос включён по умолчанию. Использует архив из репозитория и создаёт временный artifact `experimental-DATA-not-console-verified` (7 дней), **не Release**. Для собственного файла можно добавить расшифрованный DATA в репозиторий и передать относительный `input_path` при ручном запуске. Это не приватная загрузка: файл и artifact доступны пользователям с доступом к репозиторию; для сохранений с личными данными предпочтителен локальный запуск. Удаление файла из коммита не удаляет его из истории Git.

## Apollo / PS4 (только экспериментально)

1. В Apollo Save Tool сделайте резервную копию сохранения Squads и экспортируйте расшифрованное сохранение на USB; сохраните все соседние файлы и структуру каталогов. Подробности интерфейса и поддержка зависят от версии Apollo: [Apollo Save Tool](https://github.com/bucanero/apollo-ps4).
2. Пропатчите экспортированный `DATA` локально. В **копии** экспорта замените только DATA результатом, назвав его `DATA`; INDEX, NAME и `sce_sys` оставьте неизменными.
3. Импортируйте копию через Apollo в подходящий слот, соблюдая его процедуру импорта/подписи. Проверьте состав в игре. При ошибке или повреждении восстановите резервную копию. Не заменяйте файлы системного сохранения напрямую.

Процедура не проверена на консоли. При использовании другой базы или переноса данных между учётными записями могут понадобиться дополнительные действия и корректные подписи; скрипт их не создаёт.

## Известные пробелы

RM как дополнительная позиция, workrates, стили и их битовые маски, CPU traits, player roles, новая причёска, экипировка, анимации и точная внешность 2008 **не реализованы**: подходящие значения и соответствие схемы PS4 не подтверждены. Оригинальные анимации остаются как есть. Строки `playerroles` в найденном DATA нет; присутствуют `role1`–`role5` в players, но значения не декодированы. Нельзя считать современные коды из других версий игры совместимыми без проверки. Сводные карточные показатели также не изменяются. Дата 5 февраля 2002 даст 23 года на старте сезона 2025/26; значение проверено по известным датам базы, но не в игре.

Результат, проверенный парсером, не равен проверке игры. Поэтому готовый Squads в GitHub Releases не публикуется. Потребуются подтверждённая таблица кодов FC 26 PS4, проверка целостности и испытание на реальной консоли. Для описания PS4 DATA см. [FC26-PS4-SquadUpdater](https://github.com/ferrets6/FC26-PS4-SquadUpdater) и его technical reference; его алгоритм относится к замене базы целиком и не доказывает корректность этого редактора.
